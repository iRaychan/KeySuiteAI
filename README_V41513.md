# KeySuite V4.15.13

## Global Display Settings

### CHC — Selection / Quick Selection / Product

All use the same CHC saved setting.

Default:
- 2P–6P: OFF individually
- Duty Points D1–D6: ON
- System Curve: ON
- Operating Point: ON
- BEP: ON
- After-orifice Curve: OFF
- PDF Page 1 → Follow Selector Screen Settings: ON

Product CHC now shares the same CHC preference as Selection and Quick Selection.

### ES — Selection / Quick Selection / Product

All use the same ES saved setting.

Default:
- Impeller Curves: Max + Min + Duty Impeller
- 2P–6P: OFF individually
- Duty Points D1–D6: ON
- System Curve: ON
- Operating Point: ON
- BEP: ON
- After-orifice Curve: OFF
- PDF Page 1 → Follow Selector Screen Settings: ON

Efficiency / Power / NPSH are removed from the Display Settings choices. Their charts remain active.

### Reset to Default

Restores exactly these global defaults.
