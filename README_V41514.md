# KeySuite V4.15.14

## Left Panel Brand Series names

The visible series name now comes from the saved **Brand Series**.

Applies to:
- Selection → Brand → [Brand]
- Product → Brand → [Brand]
- B.G.Reich direct Product tree

Example for Price Group `ES`:
- Brand Series = `ES` → show `ES`
- Brand Series = `End Suction` → show `End Suction`

Only the display name changes. Price Group, hydraulic family, selector route, Product route, curve data and pricing remain unchanged.

CHC G1 remains hidden from Selection until a real G1 hydraulic curve is available.
